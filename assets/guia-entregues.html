Com preparar i entregar models per a Castaween

Descarrega la guia per a l'alumnat · PDF

Cada alumne pot presentar una castanyera, un monstre, un arbre o un objecte. Les propostes es guarden amb noms diferents i poden conviure dins del joc.

Descarrega les referències i la paleta

1. Acordeu què farà cadascú

Professorat: repartiu els tipus de model i feu una llista amb alumne, curs, tipus, nom de la proposta i estat de revisió. Pot haver-hi diverses carabasses o diversos castanyers: cada proposta necessita un fitxer propi.

Alumnat: tria un tipus del Taller i descarrega'n la referència al catàleg de models i mides. El GLB de referència serveix per comparar l'escala. Per practicar esquelet i animació, fes servir la plantilla animada de castanyera.

2. Prepara Blender a escala

  1. A Scene Properties → Units: Metric, Unit Scale 1.000, Length Meters. Una unitat és un metre.
  2. Importa la referència amb File → Import → glTF 2.0, sense redimensionar-la. Deixa-la en una col·lecció separada anomenada REFERENCIA.
  3. Modela al costat de la referència i comprova les dimensions del conjunt. Z cap amunt, cara principal cap a −Y, origen al centre de la base i peus o base a Z = 0.
  4. Respecta l'alçada de la taula del teu tipus. La castanyera fa 1,80 m; el castanyer, 4,30 m; el pi, 6 m. El marge ha de fer 1,20 m de llarg en X. Amplada i fondària dels altres models orienten les proporcions.

Blender converteix els eixos de glTF automàticament: al GLB l'alçada és Y. No giris el model a mà després d'importar-lo.

3. Compleix els requisits del joc

  • Un material i la paleta oficial de 256 × 256 px. A l'UV Editor, col·loca cada cara sobre la casella del seu color. La guia de colors t'ajuda a trobar-les.
  • La fila magenta és el color variable. A les castanyeres, paradetes, fogueres i torradores es converteix en el color del curs; als monstres, en lila de Halloween. No cal una còpia per a cada curs.
  • Compta triangles, no cares de Blender. Comprova el pressupost abans d'afegir detalls petits.
  • Sense càmeres, llums, shape keys ni modificadors pendents. Exclou la referència de l'exportació.

La guia tècnica i el Taller indiquen el límit de cada objecte i el nombre màxim d'ossos.

Animació: les castanyeres poden portar idle, corre, llanca i cop; els monstres, camina i ataca. Es pot començar amb un model sense esquelet: el joc hi aplica moviment automàtic. Els arbres i objectes no necessiten rig.

Els GLB de referència són instantànies dels models integrats. No són necessàriament entregues preparades amb paleta i pressupost: si els reutilitzes, revisa'ls.

4. Exporta i prova la proposta

  1. Desa el projecte .blend per poder corregir-lo. Selecciona el teu model i l'esquelet, si en té.
  2. Aplica Ctrl+A → All Transforms. Comprova de nou la mida i l'origen.
  3. A File → Export → glTF 2.0: glTF Binary (.glb), Selected Objects, +Y Up, UVs, normals i materials. Activa animacions si n'hi ha. Desactiva Draco.
  4. Posa un nom únic en minúscules, sense accents ni espais: 3d-garcia-marta-carabassa.glb. No entreguis tots els fitxers com model.glb.
  5. Obre Personatge → Taller de models, tria el tipus correcte i carrega el GLB. Revisa la figura, els colors, la mida i les animacions.
  6. Corregeix els punts vermells; revisa els grocs amb el professorat. Prova'l amb Juga amb aquest model, Fes servir aquest monstre o Posa-ho a l'escena, segons el tipus.
  7. Escriu el nom del model i l'autor/a i copia l'entrada de configuració del Taller.

El Taller és una prova local: no envia ni publica el GLB. Els companys el veuran després que el professorat l'afegeixi al projecte i el publiqui.

5. Què entrega cada alumne

  • El .glb validat, amb el nom únic.
  • El projecte .blend com a font editable, a la carpeta o plataforma de classe que indiqui el professorat.
  • Tipus de model, nom de la proposta, autor/a, curs i entrada JSON generada al Taller.

Exemple: Carabassa · La dentuda · Marta Garcia · 3D i videojocs, fitxer 3d-garcia-marta-carabassa.glb.

6. Professorat: afegeix totes les propostes

  1. Copia cada GLB a la carpeta que toca. Conserva les entregues dels altres alumnes:
assets/
  castanyeres/   → castanyeres
  monstres/      → carabassa, fantasma, carabassot
  escenari/      → arbres, construccions i objectes

Edita assets/assets.json. Afegeix les propostes a les llistes que ja hi ha; conserva també els apartats de so, música, interfície i configuració.

Exemple d'una clau dins de monstres:

"carabassa": [
  {
    "id": "carabassa-marta",
    "nom": "La dentuda",
    "autor": "Marta Garcia",
    "curs": "3D i videojocs",
    "fitxer": "monstres/3d-garcia-marta-carabassa.glb"
  },
  {
    "id": "carabassa-pol",
    "nom": "La rondinaire",
    "autor": "Pol Puig",
    "curs": "3D i videojocs",
    "fitxer": "monstres/3d-puig-pol-carabassa.glb"
  }
]

Per a arbres i objectes es fa igual, dins de escenari: "castanyer": [ ... ], "casa": [ ... ], "panellet": [ ... ], etc. Les castanyeres van totes a la llista castanyeres, sense una clau de tipus intermèdia.

  • id: únic dins del tipus. Conserva'l un cop publicat.
  • fitxer: camí relatiu a assets/, amb barres /. No hi posis C:\Users\... ni un altre prefix assets/.
  • nom, autor, curs: dades de la proposta. El nickname del jugador es configura per separat.

Els exemples indiquen el format; cal que els fitxers citats existeixin. JSON no admet comentaris ni una coma després de l'última entrada. Si el tipus abans era un camí únic, converteix-lo en una llista que inclogui la proposta anterior i les noves. Vegeu l'exemple complet d'estructura.

7. Publica i comprova-ho a l'aula

  1. Desa els fitxers i el JSON. A GitHub Desktop, revisa els canvis, fes Commit to main i Push origin. Inclou tant els GLB com el manifest.
  2. Espera que el desplegament de GitHub Pages acabi correctament a l'apartat Actions del repositori.
  3. Recarrega el joc al professor i als mòbils abans de crear la sala. Si veus una versió antiga, prova una recàrrega completa amb Ctrl+F5 a l'ordinador.
  4. Prova primer Mode local · bots. Després, el professor prem Obre una sala, comparteix el codi i prem Comença; els alumnes entren per Mode en línia amb nickname, curs i codi.

Els GLB i el manifest es publiquen a GitHub Pages. Per afegir propostes no cal tornar a desplegar el Worker de Cloudflare.

8. Com es veuran totes les entregues

  • Castanyeres: es poden triar a Personatge → Model; els bots també les utilitzen.
  • Monstres i objectes que apareixen: cada tipus recorre els seus models per torns. Un exemplar manté el model mentre és al camp.
  • Arbres i escenari fix: es reparteixen les propostes entre les posicions disponibles. La ronda següent continua el repartiment. Si només hi ha un portal i tres propostes, es veuran a les rondes 1, 2 i 3.
  • Quan n'hi ha moltes: calen prou aparicions o rondes per veure-les totes. Els models no canvien la vida, el mal, les col·lisions ni les regles.

Un fitxer que falla no impedeix carregar els dels companys. Si fallen totes les propostes d'un tipus, es fa servir el model integrat. Molts models pesants augmenten la càrrega inicial i la memòria: manteniu els límits del Taller.

Si alguna cosa no surt

  • No apareix: comprova que GLB i JSON s'hagin publicat, el camí exacte, majúscules/minúscules i que l'ID no estigui repetit dins del tipus.
  • Només el veig jo: carregar-lo al Taller no el publica; falta afegir-lo al manifest i fer push.
  • Mida o orientació incorrectes: compara'l amb la referència, revisa l'origen, aplica transformacions i exporta amb +Y Up.
  • El color del curs no canvia: revisa les UV de les peces variables sobre les caselles magenta de la paleta.
  • No veig totes les variants: deixa que apareguin més exemplars o comença una altra ronda.
  • El mòbil mostra un altre model: recarrega la versió publicada a tots els dispositius i torna a obrir la sala.
